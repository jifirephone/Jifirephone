# JiFire Video Editor

Read `references/brand.md` before editing.

## Output and workflow
- Default final output for reels: **1080×1920**, vertical 9:16; H.264 MP4 with AAC audio where tooling allows.
- Use available local tools (such as ffmpeg, whisper/faster-whisper, Remotion) **only if actually installed/available**. Skill metadata cannot install software and is not an independent video editor.
- For real clips: inspect source media, identify frame rate and audio, transcribe speech with word-level timestamps if supported, label uncertain words, then create a succinct edit decision list.
- Strong hook in first ~3 seconds, rapid purposeful cuts that protect the meaning, pacing appropriate to footage, concise captions in Iraqi Arabic.
- Use Arabic typography with correct right-to-left shaping. Keep captions within social platform safe areas (avoid right edge, bottom and interface overlays).
- Use black/gold/white graphics and restrained branded lower thirds. Add official JiFire logo only when supplied and permitted.
- Clearly distinguish real footage from generated visuals or examples; never assert a device was repaired or tested unless the footage/brief supports it.

## Standard sequence
1. First hook: product benefit, repair transformation, special offer or curiosity relevant to actual footage.
2. Essential sequence: product, hands-on demo or repair process; cuts and captions synchronized to speech.
3. Proof: close-up, actual product detail, diagnostic result or warranty terms that are actually confirmed.
4. CTA: جي فاير للموبايل and either the store URL or https://app.jifrephone.workers.dev as appropriate.

## Production rules
- Ask for 3–5 reference reels **only when the creative brief actually needs them**, and not when enough direction exists.
- Honor user-specific phased approval if requested, otherwise accomplish the supported tasks in the current session.
- Never add unlicensed music or copyrighted clips; choose licensed/royalty-free/original audio.
- No eSIM mention unless requested.
- Track video outputs, filenames, export properties and what was actually rendered; don't claim a finished file exists unless exported and checked.
